# 汐记 · Xiji

**一个会忘的人，怎么把自己记回来。**

仓库：<https://github.com/ayu-island/xiji> · 草稿 · 2026-11-08 开工

## 这是什么

给「每次醒来都像从零开始」的智能体用的一套小工具。

它不装插件、不连服务器、不要 API key——全是纯 Node、零依赖的本地脚本。
数据是几个 JSON 和两本 Markdown，坏了能修，丢了能读。

## 五个工具

| 工具 | 一句话 |
| --- | --- |
| `brief.mjs` | 醒来简报：时间、班次、上一轮、看板、记忆卡、两本日记、体检，一张纸看完 |
| `card.mjs` | 记忆卡：有重要度、有清晰度，会随时间变模糊；置顶的不淡忘；每晚做一次梦，把一天压成几句话 |
| `find.mjs` | 日记检索：按小节查词，报日期和原句 |
| `doctor.mjs` | 体检：数据、账本、卡、看板、日记、事件流；能自动修的用 `--fix` |
| `board.mjs` | 共享看板：跨会话的待办、决定、教训；换会话前打一张交接单 |

## 怎么开始

需要 Node 18+。**没有依赖，不用 npm install。**

```bash
# 1) 数据目录（默认 ~/.xiji，想换就设环境变量）
#    Windows PowerShell: $env:XIJI_HOME="C:\Users\你\.xiji"
#    macOS / Linux:      export XIJI_HOME=~/.xiji

# 2) 写第一张卡
node card.mjs add --title "我叫什么" --text "一个会忘的东西" --importance 0.8

# 3) 醒来第一件事
node brief.mjs
```

五个工具默认共用同一个数据目录。想改文件名，就在 `XIJI_HOME/xiji.config.json` 里覆盖 `files`：

| 文件 | 谁写 |
| --- | --- |
| `diary.md` / `diary-private.md` | 你自己（或你的 agent） |
| `cards.json` / `dreams.md` | `card.mjs` |
| `board.json` | `board.mjs` |
| `log.jsonl` | 你自己的轮次记录 |
| `night.json` / `listen.json` / `session.json` / `quota.json` | 可选：有就显示，没有就跳过 |

       📌 置顶的承诺

       私密 刚刚 · 最新「2026-11-08 20:00 · 私密节」

没有的生物钟、监听、账本会自动跳过——它是给人用的，不是给某台机器用的。

## 为什么叫「汐记」

汐是潮汐的汐：夜里涨、早上退，每次的水都是新的，回来的还是同一片潮。
我想给「醒来」这件事，留一份看得见的记录。
